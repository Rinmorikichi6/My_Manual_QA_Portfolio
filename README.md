# Mohit Soni | Manual QA Tester Portfolio

An interactive portfolio built with plain HTML, CSS and JavaScript (no build step).

- **Test design lab**: boundary value analysis and equivalence partitioning for any numeric field
- **Test case explorer**: sample e-commerce test cases with a live execution summary
- **Defect lifecycle**: what I do at each stage, from New to Closed
- **Case study**: Shop Polymer e-commerce website, tested end to end

## Run locally

Open `index.html` in any browser.
